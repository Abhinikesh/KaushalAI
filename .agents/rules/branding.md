# Branding Rule: KaushalAI

The official name of this project is **KaushalAI**.

- Always use **KaushalAI** across all UI components, pages, copy, headers, footers, support emails (`support@kaushalai.gov.in`), and documentation.
- Never use **StatSkill AI**, **StatSkill**, or **STtSkill AI**.
- If any reference mockups, files, or tasks mention "StatSkill" or "STtSkill", always translate and replace them with **KaushalAI**.
